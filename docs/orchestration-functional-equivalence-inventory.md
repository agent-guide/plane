# 编排域功能等价性清单（重构验收基准）

- 文档类型：验收基准（配套业务模型设计稿）
- 日期：2026-10-28
- 分支：`feature/orchestration-plane`
- 用法：实施完成逐条勾验；任何一条无归宿即不可交付。标注〔待走查〕的项实施前须补代码核实。

## 0. 处置判定原则（结合业界实践）

| 处置 | 判定标准 | 业界依据 |
| --- | --- | --- |
| **保留等价** | 行为正确且新架构下依然合理 | 等价性重构的默认档 |
| **优化重构** | 行为目标不变，但原实现受旧架构束缚（跨系统补偿/轮询/双写），新架构可简化 | 单写者原则（Single Writer）、本地事务优于分布式 Saga、事件驱动优于轮询、绞杀者模式 |
| **精简退役** | 为旧架构存在的机制本身，新架构下问题不复存在 | 删除不再需要的问题，优于解决它 |

## 1. 团队域

| 现有行为 | 新归宿 | 处置 |
| --- | --- | --- |
| 团队 CRUD、上架/归档/恢复、草稿→活跃生命周期 | AgentTeam + Plane 服务层 | 保留等价 |
| 成员管理（人类/数字员工、角色、能力标签、序号、启停、移除） | AgentTeamMember | 保留等价 |
| **团队配额**（每人 ≤5 活跃，超额 409 + 主动提示） | Plane 服务层 + 可配置项 | 保留等价（防滥用护栏，多租户标配） |
| **权限矩阵**（全员自建；创建者管理自己的；管理员全权；归档仅管理员；viewerCanManage/viewerIsAdmin 服务端判定） | Plane 服务层权限谓词（逐条复刻矩阵） | 保留等价（判定逻辑从 runtime 迁到 Plane 内，语义不变） |
| 上架前置（≥1 启用成员方可活跃） | 服务层校验 | 保留等价 |
| runtime_identities 身份表（成员↔身份映射、供给） | **精简退役**——人类=Plane 用户、数字员工=agwmngr 引用 | 精简（身份问题被新架构消解；旧 ID 映射留历史桥） |

## 2. 流程域

| 现有行为 | 新归宿 | 处置 |
| --- | --- | --- |
| 流程定义 CRUD、画布编辑、流程归项目 | WorkflowDefinition + Plane 前端沿用 | 保留等价 |
| 版本不可变、内容哈希、发布快照 | WorkflowVersion | 保留等价（业界不可变制品惯例） |
| 发布链：DAG 文件生成→上传→发布轮询→finish/failed | worker 发布适配层 | **保留等价**（Airflow 仍是发布目标；轮询保留但收窄为发布窗口内）〔待走查：DAG 生成细节完整搬移〕 |
| 引擎能力校验（节点能力 vs 引擎支持，fail-closed） | worker 发布前校验 | 保留等价 |
| 引擎连接随版本钉定（发布时解析唯一活跃连接） | env 引用 + 发布时解析记录 | 保留等价（单引擎自动解析语义不变） |
| 版本升级提示（绑定不自动跟随新发布，显式升级操作） | ProjectTeamBinding 显式升级 | 保留等价 |

## 3. 绑定域

| 现有行为 | 新归宿 | 处置 |
| --- | --- | --- |
| 项目-团队绑定（每项目一条活跃；7 项前置校验：团队存在/活跃/成员/流程已发布/引擎就绪等） | ProjectTeamBinding + 服务层校验链（逐条复刻） | 保留等价〔待走查：7 项校验逐条列表确认〕 |

| 建项目表单团队/流程联动选择 | Plane 前端沿用 | 保留等价 |

## 4. 执行域（核心，风险最高）

| 现有行为 | 新归宿 | 处置 |
| --- | --- | --- |
| 受控启动（幂等、启动恢复 recovered 语义） | 启动命令经 Outbox + 幂等键 | 保留等价 |
| **业务控制状态机**（queued/running/waiting_human/blocked/completed/failed/cancelled 转移规则 + transition_version 乐观锁 + 非法转移 409） | Inbox 事件消费器（转移规则逐条复刻；乐观锁保留） | 保留等价——**必须写成显式状态转移规格文档再实施**，这是本清单最重要的一条 |
| 交接 handoff（from/to 成员、操作历史） | 交接事件（inbox）+ 保留交接记录 | 保留等价（审计与「执行过谁的手」事实） |
| 等待人工 ↔ 恢复（waiting_human 落人工请求、答复后恢复 running、成员切换） | BusinessApproval + worker 恢复命令 | 保留等价 |
| 取消（force/graceful 两模式，取消≠已停止分开表示） | 取消命令 + 停止确认事件 | 保留等价（语义按 §7） |
| 冻结执行上下文（启动钉流程版本+哈希+成员+release digest） | WorkItemExecution.frozen_context + 执行前校验 | 保留等价（§5.2） |
| 引擎原生调度/重试/超时/持久等待 | Airflow 原生 | 保留等价（本就归引擎） |

## 6. 投影与同步域（精简最多）

| 现有行为 | 新归宿 | 处置 |
| --- | --- | --- |
| 工作项/项目 webhook 投影（issue/project → runtime 表） | **精简退役**——Plane 原生对象无需同步给自己 | 精简（问题被架构消解；对账表同退役） |
| **控制状态→工作项状态打标**（状态视图、标准状态模板、external_id 寻址、ControlStateViewService 解析） | Plane **直接更新自家 Issue 状态**（同库直写），仅保留「业务状态→工作项状态」映射规则表 | **优化**：外部打标协议（跨系统回写+状态模板映射服务）整个消失，变为库内一次状态更新；映射规则保留是因业务语义（等待确认等状态名）仍需落工作项 |
| 指派人投影（handoff→摘旧 agent/加新 agent 的 Plane bot 账号；等待人工摘牌、人答复不加牌） | worker 交接事件处理器（沿用 bot 账号机制，规则逐条复刻） | 保留等价（规则含 09-12 修过的摘牌边界，勿回退） |
| 删除对账（project.deleted 软删投影） | **精简退役**（无投影则无孤儿） | 精简 |
| 成员供给钩子（加入/改名/移出；bot 过滤；deactivate 停用映射） | **过渡保留**，终局随 runtime-token 链退役 | 保留（过渡）→ 精简（终局） |
